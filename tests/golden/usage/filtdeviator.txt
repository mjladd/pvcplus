filtdeviator:  fixed-spectrum, phase vocoder filter
	    with response-correlated frequency deviation
filtdeviator   [flags] [input file] [output file (optional)]
	    (values in brackets denote defaults)
	N:	FFT length (must be a power of 2) [1024]
	M:	window size in samples (must be a power of 2) [2*FFT]
		    (0 will automatically set window to 2*FFT size or larger)
	w:	window type: 0 = hamming,  1 = rectangular  
		    2 = Blackman,  3 = Bartlett triangular [0.]
		    4-12 = Kaiser windows for alpha = 4-12,  respectively
		    (representative sidelobe levels for alpha: 
		      4 = -30dB,  8 = -58 dB,  12 = -90 dB)
	D:	analysis frames per second [200]
	I:	time expansion/contraction factor  [1.] 
		  (duration = duration * factor, 1. = original time) 
	P:	pitch transposition in semitones (func) [0]
	a:	frequency shift factor 
		    (bin frequency adder, before -P )(func) [0.] 
	A:	gain in decibels (func)[0.] 
	b:	begin time in seconds  [0.] 
	e:	end time in seconds (0. = end of file) [0.] 
	C:	resynthesis channel (1 -> ?) (0 = all) [0] 
	h:	SOURCE gain in dB (func) [0.] 
	r:	SOURCE frequency shift in Hz (func) [0.] 
	s:	SOURCE delay time in seconds (func) [0.] 
	y:	SOURCE pitch transposition in semitones (func) [0.] 
	F:	FILTER: frequency response file 
	G:	FILTER: filtering method: 
		 0 = pass, 1 = reject (inverted response) [0] 
	Z:	FILTER FREQUENCY RESPONSE PRINTOUT: high cutoff freq in Hz [0]
		    (0 = off)
	T:	FILTER: frequency response transposition in semitones (func) [0]
	V:	FILTER: frequency response shifter (func) [0.] 
	S:	FILTER: source decibels floor 
		    (reduces filtered signal in proportion)(func) [0.] 
	     RESPONSE WARPING:
	W:	AMPLITUDE RESPONSE WARP:  index for reshaping frequency response [0.] 
		    values > 0 expand the dynamic range, 
		    values < 0 compress the dynamic range 
	    TIME DELAY:
	J:	time delay peak (func) [0.]
	j:	time delay base (func) [0.]
	o:   	time delay warp: index for reshaping time delay response [0]
	@:	delay time scaler (func) [0]
	     FILTER FREQUENCY RESPONSE -- SHELF EQ: (pre-processing)
	H:	FILTER SHELF EQ: Low shelf gain in dB [0.] 
	X:	FILTER SHELF EQ: High shelf gain in dB [0.] 
	m:	FILTER SHELF EQ: Low shelf frequency in Hz [200.] 
	R:	FILTER SHELF EQ: High shelf frequency in Hz [2000.] 
	l:      amplitude attack time  (func) [0.]
	L:      amplitude release time   (func) [0.]
	c:	RANDOM AMPLITUDE DEVIATION off = 0,  on = 1 [0]
	d:	RANDOM AMPLITUDE DEVIATION FUNCTION: response time in seconds (func) [0.]
	f:	RANDOM AMPLITUDE DEVIATION randomize mode 
		    in passband = 0,  in stopband = 1 [0]
	E:	RANDOM FREQUENCY DEVIATION MODE:
		    0 = response mode,  1 = random mode,  "file name" = file mode [0]
	B:	FILTER OUTPUT: MASTER DECAY TIME CONTROL: (func) [0.]
	q:	FILTER OUTPUT: master time delay control in seconds (func) [0.]
	Y:	FILTER OUTPUT: random time delay deviation  0 = off, 1 = on [0]
	z:	FILTER OUTPUT: random time delay deviation response time in seconds (func) [0.]
	~:	FILTER FREQUENCY RESPONSE decay time warpshape index (func) [0.]
	/:	FILTER OUTPUT: peak decay time in seconds (func) [0.]
	Q:	FREQUENCY DEVIATION FUNCTION: response time in seconds (func) [0.]
		    (random and file modes only)
	k:      FREQUENCY DEVIATION: base deviation in semitones (func) [0.]
	K:      FREQUENCY DEVIATION: peak deviation in semitones (func) [0.]
	u:      FREQUENCY DEVIATION: base frequency shift (func) [0.]
	U:      FREQUENCY DEVIATION: peak frequency shift (func) [0.]
	v:	FREQUENCY RESPONSE WARP:  index for reshaping frequency response [0.] 
		    in frequency processing (frequency deviation domain)
		    values > 0 close down response, < 0 open it up
	O:	FREQUENCY DEVIATION: master deviation control (0 (off) - 1) (func) [1.] 
		FRAME NORMALIZATION: 
	n:	Frame Normalization Decibel Limit: (0-?) 
		Scale output frame amps to match or approach input frame amps
		using the (sum of input amps)/(sum of output amps) limited to
		the Decibel limit. 0 dB prevents normalization. [0]
	x:	Frame Normalization Reference: 
		0 = Changing Input Sound, 1 = Constant Filter [0]
	p:	amplitude reports print mode: 0 = off, 1 = on [0]
	i:	time interval between amplitude reports [.25]
	g:	Optional Analysis Sound File Source (for playback comparison only) [none]
	_:	 AUTO OUTPUT SOUND FILE PLAY:
		    0  = off 
		    -1 = interactive: Prompt for each play.
		    -2 = interactive: Play once, then prompt for more.
                   1 or greater = Auto-repeat for specified repetitions. [0]
	=:	 PEAK RESCALE LEVEL 0 to -96 dB 
		    1 = Rescale to level of input file.
		    2 = Bypass rescaling. [ 1 ]
	t:	oscillator resynthesis threshold in decibels [ -96 ]
